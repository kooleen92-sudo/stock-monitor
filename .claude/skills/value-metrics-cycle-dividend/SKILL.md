# 大周期高股息龙头低估判断

## 适用场景

当用户提供一组以银行、能源、煤炭、电力、铁路、有色、基建、航运、通信、保险为主的 A 股龙头股票，并希望判断“是否低估”“优先看什么指标”“如何建立估值框架”时，使用本 skill。

尤其适用于以下股票池或相近风格：
- 农业银行
- 工商银行
- 中国海油
- 中国石油
- 中国神华
- 陕西煤业
- 长江电力
- 大秦铁路
- 紫金矿业
- 中国铝业
- 中国建筑
- 中国交建
- 中远海控
- 中国移动
- 中国石化
- 华能国际
- 中国太保
- 中国人寿

## 核心结论

对于这类**大周期 + 高股息 + 龙头国企 + 重资产/稳定现金流**股票：

### 优先级排序
1. **PB（市净率）** —— 首要低估指标
2. **股息率（Dividend Yield）** —— 核心补充指标
3. **PE（市盈率，优先 TTM 或动态）** —— 辅助指标
4. **历史分位点** —— 最实用的综合判断框架

---

## 1. PB（市净率）——首要指标

### 为什么 PB 最重要
这类股票大多具有以下特征：
- 资产占比高：矿产、油气储量、厂房、电站、铁路、港口、贷款资产、基建网络等
- 净资产相对稳定
- 利润容易受周期波动影响

因此，**PB 更适合衡量“买资产是否打折”**，安全边际通常比 PE 更直观。

### 低估参考标准
- **银行（农业银行、工商银行）**
  - PB < 0.8 倍通常有吸引力
  - 0.6-0.8 倍区间常见于历史低分位
- **煤炭 / 能源（中国神华、陕西煤业、中国海油、中国石油、中国石化）**
  - PB 历史 30% 分位以下较有吸引力
  - 接近 1 倍或以下更值得重点关注
- **有色 / 基建 / 交运（紫金矿业、中国铝业、中国建筑、中国交建、中远海控、大秦铁路）**
  - PB < 1.2-1.5 倍更值得关注
  - 若同时处于历史低分位，意义更强
- **电力 / 铁路 / 通讯（长江电力、华能国际、中国移动）**
  - 更看 PB 是否落在历史中低分位
  - 长江电力等“类债资产”尤其适合结合股息率一起看
- **保险（中国太保、中国人寿）**
  - PB 要结合内含价值 EV 一起看

### 为什么 PB 往往优于 PE
周期股利润受以下变量影响较大：
- 油价
- 煤价
- 铜价
- 运价
- 电价
- 宏观需求

因此常出现：
- 行业景气高点时，利润高，**PE 反而很低**，容易误判为便宜
- 行业景气低点时，利润差，**PE 反而很高**，容易误判为昂贵

所以这类股票更应优先看 **PB**。

---

## 2. 股息率——核心补充指标

### 为什么必须结合股息率
这类股票的投资价值，很多来自：
- 龙头地位
- 国企属性
- 现金流稳定
- 分红确定性强

高股息本质上提供了一个“现金回报安全垫”，尤其在低利率环境下更重要。

### 吸引力参考标准
- **股息率 > 4.5%-5%**：通常具备较强吸引力
- **股息率 > 6%**：对煤炭、部分能源和银行股尤其有吸引力
- **PB 低 + 股息率高**：属于经典低估组合

### 适合重点用股息率辅助判断的方向
- 银行
- 煤炭
- 能源
- 长江电力
- 中国移动
- 大秦铁路

---

## 3. PE（市盈率）——辅助指标

### 使用原则
PE 可以看，但权重低于 PB。

### 哪些情况下更适合参考 PE
- 盈利较稳定的行业：
  - 银行
  - 通信
  - 电力
- 稳定经营、现金流较好的龙头

### 低估参考
- PE 处于历史 **30%-50% 分位** 可作为辅助低估参考
- 银行股常见 **PE 5-8 倍** 时具备较好吸引力
- 可以结合 ROE 一起看：
  - **PB ≈ PE × ROE**
  - ROE 高而 PB 低，通常更具性价比

### 注意
周期底部或利润大幅波动时，PE 容易失真，不宜单独使用。

---

## 4. 历史分位点——最实用的综合判断

建议重点看以下历史分位：
- PB 过去 5-10 年历史分位
- PE(TTM) 过去 5-10 年历史分位
- 股息率过去多年分位或与国债收益率比较

### 分位判断经验
- **< 30% 分位**：相对低估
- **< 10%-20% 分位**：显著低估

在实际表达时，可以优先给出：
- 当前 PB
- PB 历史分位
- 当前 PE(TTM)
- PE 历史分位
- 当前股息率
- 是否处于值得关注的低估区

## 5. 18只股票的典型判断框架

### 银行
- 农业银行
- 工商银行

核心观察：
- **PB 为主**
- 高股息率
- PE 辅助

典型低估信号：
- PB 0.6-0.8 倍
- 股息率约 5% 或以上
- PE 5-7 倍

### 煤炭 / 能源
- 中国神华
- 陕西煤业
- 中国海油
- 中国石油
- 中国石化

核心观察：
- **PB 为主**
- 股息率非常重要
- PE 仅辅助

典型低估信号：
- PB 历史低分位
- 股息率领先
- 现金流强

### 电力 / 铁路
- 长江电力
- 华能国际
- 大秦铁路

核心观察：
- **PB + 股息率** 为主
- PE 辅助
- 兼具“类债属性”

### 有色
- 紫金矿业
- 中国铝业

核心观察：
- **PB 为主**
- 资源价格波动影响大
- PE 参考意义低于 PB

### 基建 / 交运
- 中国建筑
- 中国交建
- 中远海控

核心观察：
- **PB 为主**
- 结合订单、运价、周期弹性

### 通信 / 保险
- 中国移动
- 中国太保
- 中国人寿

核心观察：
- 中国移动：**PB + 股息率 + 现金流稳定**
- 保险：**PB + EV（内含价值）**

---

## 6. 最实用的综合低估信号

如果需要一句话总结，可优先使用这条框架：

**PB 历史低分位 + 股息率 > 4.5% + 现金流稳定 + 龙头国企属性 = 这类大周期高股息股票最值得关注的低估信号。**

进一步可以补充：
- 经济复苏时，有估值修复空间
- 高股息提供持有回报
- 适合作为防御底仓或周期修复布局

## 注意事项

输出时要提醒用户：
- 低估不等于马上上涨
- 周期股常常需要等待行业景气回升
- 不能只看单一指标
- 最好把估值、股息率、现金流、行业周期一起看
- 实时数据会波动，以最新行情、年报和软件数据为准

---

## 默认回答风格

- 先给结论，再解释原因
- 用“PB为主、股息率补充、PE辅助”的框架展开
- 避免把这类股票简单按成长股逻辑去看 PE
- 如果用户问单只股票，优先说明：
  1. 更适合看 PB 还是 PE
  2. 股息率是否重要
  3. 什么情况下算进入低估区
  4. 还需要结合哪些行业变量
